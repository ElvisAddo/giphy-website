# giphy-website
Name : Elvis Addo 
Overview/ Description of Project : This project is a web site that displays animated gifs from the giphy api 
Details on how to use it : 
To use this website 
type git clone https://github.com/ElvisAddo/giphy-website.git on terminal to get the project 
This project uses an api from giphy api you can create a giphy api and then change the api key in main.js then run the project 
Technologies Used are as follows 
Html for creating the web site structure and layout
Css for styling the website 
javascript - Ajax, Jquery formaking api calls 
Ideas for Future Improvement 
1. We can add an authentication flow where a user can login and see recently searched generated gifs
2. We can add a click event to the channels section where users can search customised gifs based on the click channel section name 
3. We can add a filter event to the filter component on the website where a user can filter a specific gif
