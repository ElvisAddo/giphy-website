📌 Overview / Description of Project

This project is a website that displays animated GIFs using the Giphy API. Users can search for GIFs and view them in a simple, fun interface.

🚀 How to Use

Clone the repository:

git clone https://github.com/ElvisAddo/giphy-website.git


Get an API key from Giphy Developers
.

Open main.js and replace the default API key with your own.

Run the project by opening index.html in your browser.

🛠️ Technologies Used

HTML → Structure and layout of the website

CSS → Styling and design

JavaScript (AJAX, jQuery) → API calls and interactivity
